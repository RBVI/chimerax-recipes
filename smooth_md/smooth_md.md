# Smooth MD Trajectory

Rewrite a trajectory with averaged coordinates using nearby frames to produce smoother-looking motions.  Usage described in [this chimerax-users message](http://www.rbvi.ucsf.edu/pipermail/chimerax-users/2019-July/000590.html).  Tested with ChimeraX 0.91 daily build on July 12th, 2019.

Python code [smooth_md.py](smooth_md.py).
